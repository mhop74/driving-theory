# Sky HDRI

`sky.exr` is a partly cloudy pure-sky HDRI from [Poly Haven](https://polyhaven.com/hdris),
released under CC0 (public domain). This 512 × 256 copy comes from the
[@pmndrs/assets](https://github.com/pmndrs/assets) package (v1.7.0, `hdri/sky.exr`, CC0-1.0),
which resizes Poly Haven HDRIs and stores them with DWAB compression.

It is used as the visible sky and as image-based lighting in the 3D hazard perception clips.
